1. **Keep related files together** - Group by feature, not by type
2. **Use clear naming** - File names should indicate purpose
3. **Avoid deep nesting** - Max 3-4 levels deep
4. **Document structure** - Keep this checklist updated

6. **README in directories** - Add README for complex directories
